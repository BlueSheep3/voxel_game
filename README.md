A Voxel Game / Minecraft clone made with Bevy 0.15.0
just for fun and testing out Bevy's features.
Also my first 3D Bevy game.


# How to Play

First create a new world by pressing the `New World` button.\
You can save it by pressing `O` or `P`,
then you'll be able to join that same world with the `Play` button.

- Move around using the WASD keys and look around by moving the mouse.
- Press Space to jump, or while flying press Space to go up and Shift to go down.
- You can place / break blocks using left / right click.
- Select different blocks by pressing the number keys (the ones at the top, not the number pad).


# Debug Hotkeys

- `F3` toggle debug info
- `esc` toggle `bevy-inspector-egui` overlay
- `B` toggle chunkborders
- `N` toggle wireframe outline
- `C` toggle flying
- `F` toggle freecam
- `E` switch between mouse moving screen and cursor being visible
- `O` save world
- `P` save and quit world
- `Q` quit game without going to main menu
- `K` save benchmarks to `%APPDATA%/../LocalLow/BlueSheep3/Voxel Game`
- `scroll wheel` increase or decrease player speed (seperate for freecam)
- `click scroll wheel` reset player speed
